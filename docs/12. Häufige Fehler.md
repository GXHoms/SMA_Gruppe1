## 12. Häufige Fehler
------------------
PostgreSQL
----------
Fehler: Chunks into Postgres: not any credentials set
Lösung: Daten aus .env übernehmen und in n8n unter "Credential to connect with" einfügen.

Ollama
------
Fehler: Problem in node 'Embeddings1' / The resource you are requesting could not be found
Ursache: Embedding-Modell ist noch nicht installiert.
Lösung (im Docker-Ordner):

docker compose exec ollama ollama pull nomic-embed-text
docker compose exec ollama ollama list

nomic-embed-text sollte in der Liste erscheinen.

Embeddings langsam/Fehler
-------------------------
- Batch-Größe reduzieren
- Retries aktivieren

RAG-Chat / Web UI
-----------------
Langsam / verzögert (abhängig von Internet/Netzwerk):
Der RAG-Chat ist in der Nutzung netzwerkabhängig. Bei schlechter Verbindung kann das UI spürbar langsamer reagieren
(z. B. beim Laden/Übertragen von Requests).
Lösung: stabile Internet-/Netzwerkverbindung nutzen oder Test im lokalen Netzwerk durchführen.

Funktioniert nicht mit aktiviertem Adblocker:
Ein aktiver Adblocker kann Requests blockieren, wodurch z. B. nur die Meldung erscheint:
"Es ist ein Fehler aufgetreten. Bitte versuchen Sie es erneut."
Lösung: Adblocker für die verwendete Web-UI deaktivieren oder eine Ausnahme (Whitelist) hinzufügen.

PDF-Download leer/fehlt
-----------------------
- Attachment-Key falsch
- Item hat kein PDF-Attachment
