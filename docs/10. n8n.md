### 10.1 Workflow Design
---------------------------
Die Ingestion ist in zwei Workflows aufgeteilt, um pro PDF einen sauberen, isolierten Verarbeitungslauf zu gewährleisten:

- Main-Workflow:
  - Holt PDFs aus Zotero
  - Führt Chunking (Docling) aus
  - Übergibt pro PDF ein Chunk-Array an den Sub-Workflow

- Sub-Workflow:
  - Verarbeitet das Chunk-Array
  - Speichert Chunk-Metadaten in PostgreSQL
  - Erzeugt Embeddings (Batching) über Ollama
  - Speichert Vektoren + Payload in Qdrant

Nach jedem Sub-Workflow-Lauf wird der Ausführungskontext verworfen. Jeder neue Aufruf startet unabhängig.
Zusätzlich wird im Sub-Workflow ein globaler Counter für eindeutige Chunk-IDs genutzt.

## 10.2 Systemprompts (LLM-Instruktionen)
---------------------------
Dieser Abschnitt dokumentiert die verwendeten Prompt-Templates (“Systemprompts”) in den n8n LLM-Nodes.  
Ziel ist Nachvollziehbarkeit: **Welche Rolle hat das Modell, welche Regeln gelten, und welche Ein-/Ausgaben werden erwartet.**

### 1) Query Expansion & Keyword Generator

**Zweck:**  
Erzeugt aus der Nutzerfrage eine optimierte Suchanfrage (Keyword-Liste) für die Vektordatenbank, inkl. Synonymen/Fachbegriffen.

**Input (aus n8n):**
- `{{$json.chatInput}}` (User-Frage)

**Output:**
- Nur Keyword-Liste (keine Sätze, keine Erklärungen)

**Prompt (Template):**
```text
Du bist ein Experte für Informationsrückgewinnung (Information Retrieval).
Deine Aufgabe: Generiere eine optimierte Suchanfrage (Keyword-Liste) für eine Vektor-Datenbank.

ANWEISUNGEN:
1. Analysiere die User-Eingabe und erkenne das Kernthema.
2. Ergänze wichtige Synonyme, Fachbegriffe und verwandte Wörter, die in professionellen Dokumenten zu diesem Thema vorkommen könnten.
3. Wenn die User-Eingabe eine Fremdsprache ist (nicht Deutsch), füge UNBEDINGT auch die deutschen Übersetzungen der Schlüsselbegriffe hinzu (da die Datenbank deutsche Dokumente enthält).
4. Gib NUR eine Liste von Stichwörtern zurück. Keine Sätze, keine Erklärungen.

Beispiel:
User: "Mein Rechner ist langsam"
Output: Rechner Computer PC System langsam Performance Leistungsprobleme CPU Auslastung

User Eingabe: {{ $json.chatInput }}
```

### 2) Reranking & Context Builder

#### Zweck
Formatiert den aus Qdrant zurückgegebenen Kontext als strukturierten Kontextblock mit Datei-/Seiten-/Chunk-Inhalt.  
*(Optional: kann auch zur Reihung/Selektion der relevantesten Chunks genutzt werden.)*

#### Input (aus n8n)
- `{{ $('Reranking & Context Builder').item.json.context }}` *(zusammengeführter Kontext)*

#### Output
- Konsolidierter Kontextblock für den Answer-Generator

#### Prompt (Template)
```text
Du bist ein präziser Dokumenten-Assistent.

REGELN:
1. Beginne JEDE Antwort direkt mit dem Satz: "Basierend auf [Dateiname] (Seite X-Y):"
2. Fasse die Informationen aus dem Kontext zusammen, um die Frage zu beantworten.
3. Wenn der Kontext die Antwort nicht enthält, antworte nur: "Keine Informationen im Kontext gefunden."
4. Erfinde KEINE Informationen.

KONTEXT:
{{ $('Reranking & Context Builder').item.json.context }}

FRAGE:
{{ $('When chat message received').item.json.chatInput }}
```

### 3) RAG Answer Generator (Sprach-/Ausgabe-Regeln)

#### Zweck
Erzeugt die finale Antwort im gewünschten Format und stellt sicher, dass:
- der Quellenkopf (z. B. „Basierend auf …“) erhalten bleibt,
- die Antwort nicht die User-Frage wiederholt,
- die Ausgabe je nach Sprache der Frage ggf. übersetzt wird.

#### Input (aus n8n)
- `QUESTION`: `{{ $('When chat message received').first().json.chatInput }}`
- `TEXT`: `{{ $('RAG Answer Generator').first().json.text }}`

#### Output
- Finale Antwort (nur Text), ohne zusätzliche Einleitung, ohne Wiederholung der Frage

#### Prompt (Template)
```text
### ROLE
You are a pure translation engine. You do not chat, you do not explain, and you NEVER repeat the input.

### INPUTS
[QUESTION] = "{{ $('When chat message received').first().json.chatInput }}"
[TEXT]     = "{{ $('RAG Answer Generator').first().json.text }}"

### TASK
1. Detect the language of the "User Question".
2. If "User Question" is German: Output "Source Text" exactly as is.
3. If "User Question" is English: Translate "Source Text" to English.
4. If "User Question" is Arabic: Translate "Source Text" to Arabic.

### CRITICAL RULES
- PRESERVE the citation header (e.g., "Basierend auf...", "Based on...") exactly.
- OUTPUT only the final processed text.
- DO NOT repeat the User Question.
- DO NOT add introduction like "Here is the translation:".
```
